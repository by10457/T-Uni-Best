# uCharts 项目集成

## 数据边界

- API DTO 先转换成图表需要的 categories/series 结构，不让组件直接依赖后端原始字段。
- 数值使用有限数字；处理 `null`、空数组、重复分类、时间排序和单位。
- formatter 只负责展示，不在渲染回调里改变业务状态。
- 图例、颜色与序列保持稳定，避免数据刷新后含义改变。

## Vue 3 与生命周期

- 页面参数在 `onLoad` 校验，数据请求沿用 `src/http`。
- 需要节点或 Canvas 就绪的初始化放在目标平台可靠的 ready/mounted 阶段。
- 容器尺寸确定后再初始化；尺寸改变时使用库支持的更新方式，不反复销毁重建。
- `onHide`/`onUnload` 或组件卸载时停止定时器、事件和异步更新。
- 异步响应返回时确认页面/组件仍然存活，避免向已销毁实例写入。

## 跨端检查

| 平台 | 重点 |
| --- | --- |
| 微信小程序 | Canvas 类型、基础库、真机触摸、分包和包体积 |
| H5 | 容器 resize、DPR、路由切换后的实例清理 |
| App | WebView/nvue 支持差异、权限和真机性能 |

使用条件编译隔离确实不同的实现，不用 UA 判断替代平台编译。

## 交互和可访问性

- 触摸提示不应成为读取数值的唯一方式。
- 给关键图表提供标题、单位、更新时间、空态和文本摘要。
- 颜色不能作为唯一编码；必要时配合图例、标签、线型或符号。
- 避免默认开启高成本动画，尊重页面滚动和手势冲突。

## 验证清单

- 正常、空数据、单点、大数据量和异常数值。
- 首次进入、返回重进、切换分包、前后台切换。
- 小屏、不同 DPR、横竖屏（若支持）和主题颜色。
- H5 与实际目标小程序/App 构建及真机行为。
